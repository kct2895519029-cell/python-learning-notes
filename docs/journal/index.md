# 学习记录与复盘

## 为什么把笔记与实际掌握分开

**“已整理资料”不等于“已经自己运行、理解和掌握”。** 每次学习后尽量保留可核查的运行输入、输出、遇到的错误以及解决办法。

| 日期 | 学习内容 | 状态 | 证据 |
|---|---|---|---|
| 2026-11-10 | 整理四大容器方法图鉴（36 个方法） | 已整理，个人逐项掌握情况未核验 | [交互式图鉴](../tools/containers.html) |

## 每次复盘至少记录

- 学过什么，哪些结论已经能用自己的话解释。
- 环境（Python 版本、操作系统、依赖包），避免例子无法重现。
- 输入代码与实际输出，尤其是错误栈和边界情况。
- 下一步练习目标与尚未解决的问题。

使用 `scripts/new_note.py` 可以自动生成下一份笔记，也可以直接在 GitHub 新建 `.md` 文件。
